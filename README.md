# Spotify Clone 🎵

A responsive Spotify-inspired music player UI built using HTML and CSS. The project recreates the modern Spotify web player interface including sidebar navigation, music player controls, playlists, cards section, and responsive layouts.

---

## 🚀 Features

- Spotify-inspired UI Design
- Responsive Layout
- Sidebar Navigation
- Sticky Navbar
- Music Player Interface
- Playlist & Card Sections
- Interactive Hover Effects
- Progress Bar UI
- Mobile Responsive Design using Media Queries
- Clean Flexbox-based Layout

---

## 🛠️ Tech Stack

### Frontend

- HTML5
- CSS3
- Font Awesome Icons
